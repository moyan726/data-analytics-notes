## 项目案例

### 1. 西雅图房价预测项目 (Seattle House Price Prediction)

这是一个经典的回归预测项目，也是我系统性实践机器学习建模流程的起点。

- **核心内容**：从基线 MLP 模型出发，通过特征工程（KNN 空间滞后特征、地理聚类等）、目标变换（Log1p）、模型融合（Stacking）等手段，逐步攻克房价预测中的偏差、方差与噪声问题。
- **关键技术**：
    - **特征工程**：处理共线性、构建空间特征、Haversine 距离计算。
    - **模型构建**：使用 TensorFlow (MLP)、XGBoost、LightGBM、CatBoost 等异构模型。
    - **模型融合**：实施 Stacking 集成策略，显著提升预测精度。

## 常见坑与经验总结

- **数据决定上限**：特征工程往往比模型调优更重要。不要迷信复杂模型，先从数据中挖掘更多信息。
- **验证策略至关重要**：合理的交叉验证方案（如 K-Fold）能有效防止过拟合，确保模型在未知数据上的泛化能力。
- **重视基线模型**：先跑通一个简单的 Baseline，作为后续优化的参照系。没有对比就没有伤害（也就没有进步）。
