## 1）谷歌 5 天 AI 代理强化课（5-Day AI Agents Intensive，Google × Kaggle）

2) Kaggle｜5-Day AI Agents Intensive Course with Google（自学指南）
https://www.kaggle.com/learn-guide/5-day-agents

**它是什么**：Google 与 Kaggle 联合做的 5 天游泳式（hands-on）Agent 课程，最初是 **2025/11/10–11/14** 直播开营，后来整理成 **Kaggle Learn 自学指南**，可以按节奏完成练习。 ([Kaggle](https://www.kaggle.com/learn-guide/5-day-agents))

**核心“构建五步法/五组件”**：课程主线就是把 Agent 做成“可落地系统”，强调

- **模型（Model）**：选型与能力边界
- **工具（Tools）**：让模型会调用外部能力/API
- **编排（Orchestration）**：任务拆解、控制流、多步执行
- **记忆（Memory）**：短/长记忆与上下文管理
- **评估（Evaluation）**：可靠性、成本/延迟、上线前验证
  这些关键词在官方介绍里被反复强调，目标是从 prototype 走到 production。 ([blog.google](https://blog.google/technology/developers/ai-agents-intensive/?utm_source=chatgpt.com))

**适合谁**：想系统补齐 Agent 工程化要素的开发者/数据科学/产品工程团队（尤其想做“工具调用+评估+上线”闭环的人）。 ([blog.google](https://blog.google/technology/developers/ai-agents-intensive/?utm_source=chatgpt.com))

但你括号里的学习主题非常典型，核心逻辑一般会围绕：

- **分散化（Diversification）**：用低相关资产组合来平滑非系统性风险；分散的效果会递减，且依赖相关性结构。 ([Investopedia](https://www.investopedia.com/terms/d/diversification.asp?utm_source=chatgpt.com))
- **现代组合理论（MPT）/有效前沿**：用“组合里的相互作用”看风险收益，而不是只看单个标的。 ([Investopedia](https://www.investopedia.com/managing-wealth/modern-portfolio-theory-why-its-still-hip/?utm_source=chatgpt.com))
- **再平衡（Rebalancing）**：定期把资产配比拉回目标区间，维持风险暴露。 ([Investopedia](https://www.investopedia.com/how-to-rebalance-your-portfolio-7973806?utm_source=chatgpt.com))
- **AI 在投资中的常见用法**：信息检索与总结、因子/特征工程辅助、回测与情景分析自动化（但仍要注意数据偏差与“看似聪明的过拟合”）。

## 4）Anthropic 的 MCP 协议研讨会（模型上下文协议）

 

MCP｜官方文档（Model Context Protocol）
https://modelcontextprotocol.io/docs/getting-started/intro

5) MCP｜官方规范（Specification）
https://modelcontextprotocol.io/specification/2025-03-26

6) MCP｜GitHub（规范/Schema/文档源码）
https://github.com/modelcontextprotocol/modelcontextprotocol

7) Anthropic｜Introducing the Model Context Protocol（官方发布文章）
https://www.anthropic.com/news/model-context-protocol

**MCP 是什么**：Anthropic 发起的 **开放标准**，目标是把 AI 助手与“数据所在系统/工具所在系统”（如内容库、业务工具、开发环境）标准化连接起来，让模型拿到它需要的上下文并执行工具调用。 ([Anthropic](https://www.anthropic.com/news/model-context-protocol?utm_source=chatgpt.com))

**研讨会通常会讲什么**（你括号里“详解”很贴切）：

- 协议角色与架构：Host/Client/Server 的职责边界
- “工具、资源、提示”等对象如何被暴露给模型
- 传输与实现要点（例如本地/远程对接方式、schema/规范约束等） ([model-context-protocol.github.io](https://model-context-protocol.github.io/specification/?utm_source=chatgpt.com))
- 安全与治理：权限、认证、提示注入/数据泄露等风险面如何控制

**最近动态**：MCP 的治理正在走向更“中立开放”的路线——媒体报道 Anthropic 已把 MCP 捐赠给 Linux Foundation 体系下的新组织以推动开放标准生态。 ([WIRED](https://www.wired.com/story/openai-anthropic-and-block-are-teaming-up-on-ai-agent-standards?utm_source=chatgpt.com))
