# 🧭 AI Navigator 使用指南

> 安装步骤请参考 [README.md](./README.md)

---

## ✨ 功能概览

AI Navigator 是一款**通用 AI 对话导航助手**，让你在长对话中快速定位任意问题。

### 🌐 支持平台

| 平台 | 网址 |
|-----|------|
| Google Gemini | gemini.google.com |
| ChatGPT | chatgpt.com / chat.openai.com |
| Claude | claude.ai |

---

## 🎯 核心功能

### 1. 快速导航
- 面板列出所有用户提问
- **点击条目** → 平滑滚动到对应位置
- **当前位置蓝色高亮**，滚动页面时自动更新

### 2. 搜索过滤
- 顶部搜索框支持**实时过滤**
- 输入关键词，只显示匹配的对话

### 3. 隐藏与恢复
- 点击条目右侧 `−` 隐藏该条目
- 底部出现 **"↩ 恢复隐藏项"** 按钮，一键恢复所有

### 4. 悬浮模式
- 开启后，鼠标离开面板 **5 秒后自动收起**为 🧭 小图标
- 点击小图标即可展开

---

## 🎨 个性化设置

点击面板上的 **⚙ 齿轮按钮** 或右键扩展图标选择"选项"进入设置页面。

| 设置项 | 选项 |
|-------|------|
| 语言 | 中文 / English |
| 主题 | 自动 / 浅色 / 深色 |
| 编号样式 | `1.` / `(1)` / `#1` |
| 显示条数 | 4 / 6 / 8 / 10 / 15 / 20 条 |
| 悬浮模式 | 开启/关闭 |

所有设置**实时生效**，无需刷新页面。

## ⌨️ 快捷键

| 快捷键 | 功能 |
|-------|------|
| `Ctrl + Shift + G` | 显示/隐藏面板 |
| `Alt + ↑` | 上一个问题 |
| `Alt + ↓` | 下一个问题 |
| `Esc` | 最小化面板 |

---

## 🔧 交互操作

### 拖拽移动
- 按住**标题栏**拖动，定位到任意位置
- 位置自动保存，刷新后恢复

### 调整大小
- 拖拽面板的**右侧 / 底部 / 右下角**边缘
- 尺寸自动保存

### 字体调节
- 点击 **A** 按钮，选择 12px / 14px / 16px

### 边缘自动恢复
- 如果面板被拖到屏幕边缘导致标题栏被遮挡
- **3 秒后自动滑回**安全位置

## 💡 项目亮点

### 🚀 性能优化
- 使用 `MutationObserver` 监听 DOM 变化，**零轮询**
- 使用 `IntersectionObserver` 追踪滚动位置
- 轻量级，几乎不影响页面性能

### 🎭 智能适配
- **适配器模式**：每个平台独立适配器
- **多重后备选择器**：平台 DOM 更新后仍能工作
- **SPA 导航检测**：切换对话时自动重置状态

### 🛡️ 用户体验保护
- **拖拽边界保护**：始终保留 25% 可见区域
- **边缘自动恢复**：防止面板"丢失"
- **5 秒延迟收起**：避免调整大小时误触

### 🌍 国际化
- 中英文手动切换
- 面板和设置页面完整本地化

## 🐛 常见问题

**Q: 面板不显示？**
- 确认当前页面是支持的平台
- 刷新页面或按 `Ctrl+Shift+G`

**Q: 设置没有保存？**
- 点击"保存设置"按钮
- 确认右上角显示"✓ 设置已保存"

**Q: 面板位置"丢了"？**
- 等待 3 秒，会自动恢复到安全位置
- 或按 `Ctrl+Shift+G` 重新显示
