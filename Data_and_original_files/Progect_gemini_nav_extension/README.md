# Gemini Navigator

快速跳转 Gemini 对话的 Chrome 插件。

## 安装方法

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择 `gemini-nav-extension` 文件夹

## 使用说明

- 插件会在 Gemini 页面右侧显示一个浮动面板
- 最多显示 6 个对话预览
- 点击条目跳转到对应对话
- 点击 **−** 按钮隐藏该条目
- 当前位置会高亮显示（蓝色）

## 功能特点

- 简洁 UI 设计
- 平滑滚动跳转
- 自动检测新对话
- 滚动时自动高亮当前位置
