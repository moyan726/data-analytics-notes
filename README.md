## 🚀 特性 (Features)

- **结构化知识体系**：从基础语法到实战项目，循序渐进。
- **沉浸式阅读体验**：使用 Material for MkDocs 主题，支持深色模式、代码高亮、复制、搜索。
- **可视化辅助**：大量使用 Mermaid 流程图、表格和截图辅助理解。
- **实战导向**：包含真实数据集分析项目（如淘宝用户行为分析）。

## 🛠️ 本地运行 (Run Locally)

如果你想在本地查看或修改文档：

1. 克隆仓库：
   ```bash
   git clone https://github.com/moyan726/data-analytics-notes.git
   ```

2. 安装依赖 (Python 3.x)：
   ```bash
   pip install mkdocs-material mkdocs-git-revision-date-localized-plugin
   ```

3. 启动本地服务器：
   ```bash
   mkdocs serve
   ```
   访问 `http://127.0.0.1:8000` 即可。
