## 具体修改方案
### A) 文案可读性与抗溢出（现在要改）
**文件**：[custom.css](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/stylesheets/custom.css)
- 处理 `white-space: nowrap`（header/status/li）：
  - 将 `.side-announcement-header`、`.side-announcement-status`、`.side-announcement-list li` 的 `white-space: nowrap;` 改为允许换行：
    - `white-space: normal;`
    - `word-break: break-word;`
  - 为避免 flex 子元素不换行：给文本 span 补 `min-width: 0;`（只加到必要的子节点）。
- 宽度策略由固定值改为自适应：
  - `.side-announcement { width: 220px; }` → `width: clamp(200px, 16vw, 240px);`

### B) 动画与性能：pulse 限次/仅在状态变化触发（现在要改）
**文件**：[custom.css](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/stylesheets/custom.css)
- 目标：关闭时不跑；打开时跑 3 次后停。
- 具体做法（纯 CSS 版本，最小改动）：
  - 默认（关闭时）禁用 pulse：
    - `.side-announcement-toggle:not(:checked) ~ .side-announcement .pulse { animation: none; }`
  - 打开时启用并限制次数：
    - `.side-announcement-toggle:checked ~ .side-announcement .pulse { animation: pulse 2s ease-in-out 3; }`
- `prefers-reduced-motion: reduce` 仍保留并覆盖以上规则（reduce 时完全不动）。

### C) 小屏策略：localStorage 记忆折叠状态（现在要改）
**文件**：[site.js](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/javascripts/site.js)、[index.md](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/index.md)
- 在 `index.md`：
  - 给 checkbox 增加 `id`，并加 `aria-controls` 指向面板 id。
  - 给 `<aside class="side-announcement">` 增加 `id`。
- 在 `site.js`：新增一个很小的初始化函数（不改变现有 onRouteUpdate 逻辑）：
  - 页面加载/路由切换时：读取 `localStorage`（如 `side_announcement_open`）并设置 checkbox 的 `checked`。
  - checkbox change 时：写回 `localStorage`。

### D) 可访问性：aria-expanded/aria-controls + Esc 关闭（现在要改）
**文件**：[site.js](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/javascripts/site.js)、[index.md](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/index.md)
- `aria-controls`：由 HTML 固定提供（见上）。
- `aria-expanded`：由 JS 在每次状态变化时同步到 checkbox（`true/false`）。
- Esc 关闭：在页面 keydown 监听 `Escape`，若面板打开则取消勾选并写回 localStorage。
- 保持向后兼容：JS 失效时不影响 checkbox 的基本折叠功能；只是少了“记忆/aria 动态/ESC”。

### E) 方案 B：左侧把手（最小改动落地）
**文件**：[custom.css](file:///e:/pycharm/MyWeb/data-analytics-notes/docs/stylesheets/custom.css)
- 将容器从右侧改为左侧：
  - `.side-announcement-container { right: 15px; }` → `left: 15px;` 并删除 `right`。
- 调整 flex 排列，让把手贴边：
  - `flex-direction: row-reverse;` → `flex-direction: row;`（把手在最左，面板在其右）。
- 调整面板隐藏方向：
  - `.side-announcement { transform: translateX(110%); }` → `translateX(-110%);`
  - `:checked` 状态保持 `translateX(0)` 不变。
